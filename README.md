# Сапёр 3D

Трёхмерная версия игры "Сапёр". Вместо клеток кубы, у каждого из которых 26 соседей вместо привычных 9.

## Установка и запуск

1. Установите Python 3.8 или новее
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите игру: `python Main.py`

## Управление

- **Левая кнопка мыши** — открыть клетку
- **Правая кнопка мыши** — поставить/убрать флаг
- **Зажатая правая кнопка** — вращение камеры
- **Средняя кнопка** — изменение точки вращения камеры

## Особенности

- 3D игровое поле
- Интерактивное обучение
- Настраиваемый размер поля и количество мин
- Секретная пасхалка (шанс 0.001%)
